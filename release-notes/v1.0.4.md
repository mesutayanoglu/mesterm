- New look: the app name and a search box in the title bar, a "+" next to the connection filter, card-style tabs, and a status bar with the active session and the main shortcuts.
- Command palette (Ctrl+Shift+P or the search box): find and open a connection, or run a command.
- Shortcuts: Ctrl+Shift+T new connection, Ctrl+Tab / Ctrl+Shift+Tab switch tabs, Ctrl+Shift+W close tab, Ctrl+Shift+D split view, Ctrl+, settings. Plain Ctrl keys still go to the session.
- The connection tree works from the keyboard: arrows, Enter, F2 to rename, Delete, / to filter. Optional Vim keys in Settings > Keyboard.
- Folders show no item count and no icon; connections keep their device logo and show their address.
- A terminal shows a bar while connecting, and after a failure or the end of the session, with Reconnect and Close tab.
- Settings: a section list, colour schemes shown as small terminals, a contrast check, a searchable font list and a size stepper.
