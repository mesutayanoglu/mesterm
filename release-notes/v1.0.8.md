- MCP uses far fewer tokens: send_command now waits for the prompt and returns the command's own output, so the agent no longer has to read the screen after every command.
- Paging is turned off automatically on Aruba, Cisco, Palo Alto and Huawei, and "--More--" prompts are answered for the agent.
