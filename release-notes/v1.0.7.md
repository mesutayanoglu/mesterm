- MCP: a connected agent now sees the whole app (every connection, folder, open tab and terminal) without allowing connections one by one. Read-only commands such as show, display, get and ping run at once; changes, unknown commands and anything in configuration mode ask you first. The agent also has to say whether each command reads or changes; both sides must agree before anything runs unasked. Settings has "Ask before every command" for stricter use. Usernames and passwords are never shared.
- Removed the shortcut hints from the status bar and the search box, and the split view icon from the tab strip (split view is in the tab's menu, the search box and Ctrl+Shift+D).
- The status bar no longer shows the terminal size and encoding.
- "Select all" is gone from the + menu; Ctrl+A still selects everything.
